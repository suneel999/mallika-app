# Mallika Hospitals patient app

Flutter application for Android and iOS. The root `README.md` has setup and run commands.

`lib/app/` starts the app and holds the theme. `lib/core/config.dart` reads `API_BASE_URL`. `lib/features/home/` is a placeholder screen only.

Approved Google Stitch designs replace the placeholder. Do not add hospital logos, addresses, phone numbers, or doctor profiles until those assets are supplied.

Further feature packages, added with their screens: onboarding, authentication, doctors, services, bookings, notifications, and profile. Shared widgets go in `lib/shared/` when a second screen needs them.

The blue colour and the application id are provisional. See `docs/PROJECT_DECISIONS.md`.
